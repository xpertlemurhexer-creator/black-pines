# Black Pines

A hardcore survival horror game set in a forest at night, playable in the browser.

Find the five videotapes and bring them to the VCR at Ranger Station 4, while something in the trees tests how you react and learns how to hunt you.

Headphones recommended. Use a desktop browser with a keyboard and mouse.

## Controls

| Key | Action |
| --- | --- |
| W A S D | Move |
| Shift / C | Run / crouch |
| Mouse | Look, click to strike or shoot |
| E | Take, use, interact |
| R | Fill bottle at water |
| F / B | Flashlight / swap batteries |
| Tab | Pack, crafting, ripping, notes, saving |
| 1–8 | Hands, knife, spear, bow, torch, axe, sling, shotgun |
| Z / G | Sleep / hold compass |
| V | Switch look: realistic, VHS tape, camcorder |

To playtest survival alone, untick **The Watcher (monster)** on the title or pause screen.
